## Critérios de avaliação do trabalho das empresas

O trabalho será avaliado de 0 a 10 pontos, considerando os seguintes critérios:

1. **Entrega no Git compartilhado — 1,0 ponto**
   O projeto deve estar publicado no repositório compartilhado [Projeto](https://github.com/rvarjao/sinerge-2o-ano-ds-empresas), contendo os arquivos necessários para funcionamento.

2. **Entrega no Git individual — 1,0 ponto**
   Cada integrante deve ter o projeto publicado em seu próprio GitHub ou demonstrar claramente sua participação no repositório do grupo.

3. **Organização do projeto — 1,0 ponto**
   O repositório deve estar organizado, com nomes de arquivos claros, estrutura compreensível e, preferencialmente, um arquivo README explicando o projeto.

4. **Banco de dados funcionando — 1,5 ponto**
   O banco de dados deve estar configurado corretamente, com tabelas adequadas ao projeto da empresa.

5. **Leitura de dados do banco — 1,5 ponto**
   O sistema deve conseguir buscar informações no banco de dados e exibi-las corretamente na tela ou no terminal.

6. **Gravação de dados no banco — 1,5 ponto**
   O sistema deve permitir cadastrar novas informações e salvar esses dados no banco.

7. **Relação com a empresa escolhida — 1,0 ponto**
   O sistema deve estar conectado com a proposta da empresa criada pelo grupo, usando dados e funcionalidades coerentes com o negócio.

8. **Originalidade e personalização — 1,0 ponto**
   O trabalho deve apresentar adaptações próprias do grupo, evitando ser apenas uma cópia direta do exemplo feito em aula.

9. **Apresentação e explicação — 0,5 ponto**
   O grupo deve conseguir explicar o funcionamento do sistema, o papel do banco de dados e as principais partes do código.
